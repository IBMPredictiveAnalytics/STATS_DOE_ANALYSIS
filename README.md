STATS_DOE_ANALYSIS
==================

Design of Experiments: generate optimal, factorial, screening,
response-surface, and other experimental designs; analyze the resulting
(or an existing) dataset; and plan sample size with a power calculator.

Supports Optimal, Factorial, Plackett-Burman, RSM, Box-Behnken, CCD,
Taguchi, Latin Hypercube, Definitive Screening (DSD), and Full Factorial
designs, with model fitting, effect plots, variable selection, and an
interactive HTML report.

Requirements
------------

* IBM SPSS Statistics 18 or later
* IBM SPSS Statistics - Integration Plug-in for R
* R package: AlgDesign (required)
* R packages (optional, enable additional design types/output when installed):
  FrF2, rsm, desirability, BsMD, ggplot2, gridExtra, leaps, plotly,
  htmlwidgets, jsonlite

Installation instructions
--------------------------

1. Open IBM SPSS Statistics
2. Navigate to Utilities -> Extension Bundles -> Install Extension Bundle
3. Select STATS_DOE_ANALYSIS_v12.spe and click Open. Your extension will be available.

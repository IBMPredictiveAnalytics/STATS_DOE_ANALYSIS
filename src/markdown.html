STATS DOE ANALYSIS Extension Command

Design of Experiments: generate optimal, factorial, screening, response-surface, and other experimental designs; analyze the resulting (or an existing) dataset; and plan sample size with a power calculator. This page is organized to match the dialog: each section below corresponds to one of the dialog's buttons (Factor Settings, Options, Constraints, Design Options, Analysis, Output, Screening, Power). The Help (?) button on the main dialog opens this page; the buttons on each individual sub-dialog do not open their own help (a limitation of the dialog platform), so use the links below to jump straight to the section you need.

  • Main Dialog — Generate Design, Variable Names, Model Type, Design Type, Output Dataset
  • Factor Settings — Lows, Highs, Centers, Round-tos, Levels, Factors, Mixtures
  • Options — Optimal Design search algorithm settings
  • Constraints — restrict the candidate design region
  • Design Options — randomize, blocks, replicates
  • Analysis — fit a model, plots, optimization, variable selection
  • Output — confounding, tables, HTML export
  • Screening — screening center points, Augment to CCD
  • Power — power and sample size planner

Main Dialog — Generate Design, Model Type, Design Type

Generate Design (GENERATEDESIGN) turns design generation on or off. When checked (YES, the default), the procedure builds a new experimental design from Variable Names and Factor Settings, and the Output Dataset field becomes required. When unchecked (NO), the procedure instead reads the active dataset for analysis only — Variable Names, Factor Settings, Model Type, Design Type, and the Options/Constraints/Design Options screens are all unused in that mode and are greyed out, and Output Dataset becomes optional (it is only needed if you also use Augment to CCD on the Screening screen, which saves its own augmented dataset).

Variable Names (VARNAMES) lists one or more variable names for the design variables, separated by spaces. The order here sets the order used by every Factor Settings field.

Model Type (MODEL / FORMULA) selects the curvature model used when Design Type is Optimal Design: Linear, Quadratic, Cubic, CubicS (a version of the cubic model that stays non-singular for mixture variables), or a Custom Formula. A custom formula is an R model formula starting with ~, using +, *, and : for linear, interaction, and nested terms (e.g. ~x1 + x2 + x1*x2); the variable names in the formula must match Variable Names. Either Model Type or a custom Formula must be given, not both. Model Type only applies to Optimal Design — every other Design Type builds its own intrinsic run structure and ignores this setting.

Design Type (DESIGNTYPE) chooses the kind of design to generate:

  • Optimal Design — Monte Carlo D- or A-optimal search (see Options)
  • Factorial Design — full or fractional 2-level factorial, 2^k runs
  • Plackett-Burman Design — screening design, runs round up to a multiple of 4
  • Response Surface Design — for optimization studies
  • Box-Behnken Design — 3-level design for quadratic models
  • Central Composite Design (CCD) — factorial core plus axial/star points
  • Taguchi Design — orthogonal array, runs round up to a power of 2
  • Latin Hypercube Sampling — space-filling design for simulation
  • Definitive Screening (DSD) — 3-level screening design, runs = 2k+1
  • Full Factorial — every combination of every factor's levels

Output Dataset (SAVE DATASET) names the dataset that receives the generated design (or the augmented design, if Augment to CCD is used). The name must not already be in use. It is required whenever Generate Design is checked; otherwise it is optional.

Factor Settings

One value is given per variable in Variable Names (or a single value to apply to all variables). The first four properties do not apply to factor variables, but a value must still be given for them if the design mixes factor and non-factor variables, to keep every list aligned by variable position.

  • Lows (LOWS) — minimum values
  • Highs (HIGHS) — maximum values
  • Centers (CENTERS) — centering values; left blank, the midpoint of Lows/Highs is used automatically
  • Round-tos (ROUNDTOS) — number of decimal places to round sampled values to (e.g. 2 rounds to two decimal places)
  • Levels (LEVELS) — number of distinct levels to sample from; 0 or blank uses a default (2 for most designs, or more automatically for a curvature Optimal model, to avoid a singular design)
  • Factors (FACTORS) — Yes/No: is this variable categorical?
  • Mixtures (MIXTURES) — Yes/No: is this variable part of a mixture? Mixture variables are always sampled between 0 and 1, and if any variable is a mixture the constant term is automatically suppressed. A variable flagged as both Factor and Mixture is treated as a mixture.

Lows and Highs are required for every ordinary (non-factor, non-mixture) variable.

Options

Controls the Optimal Design search algorithm.

  • Criterion (CRITERION) — D (a scaling of the generalized variance of the design matrix) or A (proportional to the average variance of the parameter estimates)
  • Center points (CENTER) — whether non-factor variables are centered before a design is evaluated
  • Random start (INITIAL) — Random or Nullification. Nullification successively adds points from fresh samples of candidate points and generally produces better designs, at the cost of more time
  • Design algorithm (DESIGNALG) — Exact (an exact design is calculated) or Approximate (an approximate theory design is calculated)
  • Repeats (REPEATS) — how many times the whole search is repeated, keeping the best design found (default 5)
  • Num. candidates (NUMCAND) — number of candidate points to generate; defaults to ten times the number of terms in the model
  • Trials (TRIALS) — number of runs in the design; defaults to the number of model terms plus five, must be more than the number of terms and no more than Num. candidates
  • Constant (CONSTANT) — include a constant term (automatically suppressed for mixtures)
  • Mixture sum (MIXTURESUM) — the sum mixture variables must add to (default 1)

Constraints

By default every point within the Lows/Highs ranges is a valid candidate. A constraint function (CONSTRAINTFUNC) restricts the candidate region across variables: it names a file containing an R function called dfilter that takes a candidate point's coordinates and returns TRUE (keep) or FALSE (reject). Example:


dfilter = function(x) {
    if (sum(x) <= .75) {
        return(TRUE)
    } else {
        return(FALSE)
    }
}

This keeps only candidate points whose coordinates sum to .75 or less. Only used with Optimal Design.

Design Options

  • Randomize run order (RANDOMIZE) — randomize the run order of the generated design
  • Blocks (BLOCKS) — number of blocks to divide the design into
  • Replicates (REPLICATES) — number of times to replicate the entire design (applies to Optimal, LHS, Taguchi, Box-Behnken, CCD, and RSM designs)

Analysis

Analyze (ANALYZE) fits a model to the response and enables the rest of this screen.

Response Variable (RESPONSEVAR) names one or more response variables to analyze; with more than one, results are produced for each.

Create plots (CREATEPLOTS) turns on the plot options below it: Main Effects, Interactions, Cube Plot, Contour Plot, Residual Plots, Pareto Plot, Curvature Plot (average response at factorial/cube points vs. center points), and External Plots.

Optimize response (OPTIMIZERESPONSE) searches for factor settings that best satisfy an Optimization goal (OPTIMIZATIONGOAL): Maximize, Minimize, or Target. With multiple response variables, per-response goals can be given in Optimization goals (OPTIMIZATIONGOALS); any left unset fall back to the single Optimization goal.

Variable selection (VARSELECT) reduces the model with either the Method (VARSELMETHOD) Stepwise (AIC-based, direction set by Step direction / STEPDIR: Both, Forward, or Backward) or Best Subsets. Selection Trace, Fit Profile, Parsimony Plot, and Factor Map are optional diagnostic charts for the selection process.

Output

Confounding (CONFOUNDING) displays a table of the regression coefficients of each variable on all the others (this same checkbox also appears on the Options screen; both control the same setting). Additional tables: Effects table (EFFECTSTABLE), Residual tests (RESIDUALTESTS), VIF table (VIFTABLE, variance inflation factors), Optimal design detail table (OPTDETAILTABLE), and Screening summary (SCREENINGSUMMARY, an effect-ranking table for screening designs). Export HTML (EXPORTHTML) additionally writes an interactive HTML report; its location is set by HTMLPATH, or otherwise defaults to a timestamped file next to the dataset.

Screening

Screening center points (SCREENINGCENTERPTS) adds center points to a 2-level screening design; count (SCREENINGCENTERPTSCOUNT) sets how many. Only meaningful when Generate Design is checked.

Augment to CCD (AUGMENTTOCCD) is a sequential-design feature: it reads an existing factorial design and response data from the active dataset and adds axial (star) points to form a face-centered Central Composite Design, saved to a new dataset named in Output Dataset. Augment center points (AUGMENTCENTERPTS) sets how many center points to add. Unlike the other controls on this screen, Augment to CCD works whether Generate Design is checked or unchecked — the typical use is with Generate Design unchecked, augmenting a design you already ran.

Power

A standalone power and sample size planner, independent of Generate Design — useful for deciding how many runs a design needs before building it.

  • Display power and sample size table (POWERTABLE) turns the calculator on
  • Effect sizes (POWEREFFECTSIZES, in standard deviation units) and Number of runs to evaluate (POWERRUNS) each accept one or more values, evaluated in combination
  • Significance level / alpha (POWERALPHA) — default 0.05
  • Target power (POWERTARGET) — default 0.8

An Operational Note

If there is only one design variable, it will always be named X1, and some numbers in the design evaluation table will be missing.
